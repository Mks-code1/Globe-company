# Globe Contracting Company — Design System (v2: dark-first, cinematic, motion-led)

> مكتوب ليُقرأ من **Claude أثناء البناء**. ضعه في `docs/design-system.md` بالمستودع، مع `tokens.css` و`motion.ts`. مصدر الحقيقة الوحيد للتصميم. إذا احتجت قراراً بصرياً غير موجود هنا: **توقف واسأل**.

## 0. المصدر ودقته

- **[مقاس]** مأخوذ فعلياً من الشعار ولقطات الموقع القديم (Hero + القائمة، 1920px): ألوان بالبيكسل وأبعاد.
- **[قرار]** اتجاه اعتُمد من صاحب المشروع: عصري وفخم، غير تقليدي، داكن بالغالب، IBM Plex، حركة عبر GSAP + Lenis + Motion.
- **[مقترح]** امتداد منطقي للعناصر التي لم تُرَ بالموقع القديم (البطاقات، الفلاتر، النماذج، الفوتر). تحتاج مطابقة قبل الإطلاق.

## 1. المبادئ

1. **ثلاثة ألوان: أحمر وأسود وأبيض.** الصور (المشاريع الليلية والمعدنية) هي ما يجلب الألوان الأخرى للواجهة. لا لون رابع. [مقاس + قرار]
2. **داكن بالغالب (cinematic).** سطح الصفحة `ink-950`، نص أبيض، والأحمر لمسة رفيعة. أشرطة فاتحة (`data-theme="light"`) فقط لإيقاع بصري عند الحاجة. [قرار]
3. **هندسة حادة:** صفر تدوير، صفر ظلال. حواف مستقيمة وخطوط رفيعة، تعطي إحساساً صناعياً راقياً. [مقاس]
4. **الفخامة من ثلاثة أشياء:** خط راقي بأحجام ضخمة، مساحات فارغة سخية، حركة مدروسة. لا زخارف.
5. **الصور بطلة الصفحة:** بعرض كامل، بتعتيم أسود فقط (لا تدرجات ملونة).
6. **الحركة تخدم القراءة:** تكشف المحتوى وتوجه العين، ولا تخفيه ولا تؤخّر الوصول إليه.
7. **سمة الشعار:** القضيب الأحمر السفلي، وسطر Eyebrow بحروف متباعدة. [مقترح مشتق]

**قواعد اللون**
- نص أحمر = `text-accent-text` دائماً (يتبدل حسب الثيم). لا تستخدم `brand-500` كنص صغير على الداكن.
- زر أحمر: `bg-accent text-on-accent`. Hover يفتح اللون على الداكن ويغمّقه على الفاتح (محسوب بالتوكنز).
- الأخطاء بالنماذج: أيقونة + نص + حد 2px، لا تعتمد على اللون وحده (الأحمر هو لون العلامة).
- التدرجات الوحيدة المسموحة: تعتيم أسود فوق الصور (`--overlay-hero`, `--overlay-card`).

## 3. الخطوط [قرار]

- **IBM Plex Sans** (لاتيني) + **IBM Plex Sans Arabic** (عربي)، عبر `next/font/google`. وزن 400/500/600/700.
- الاستخدام: Display 700، العناوين 600، النص 400، الـ eyebrow 600 uppercase.
- **تراكيب العنوان الإنجليزي:** تباعد حروف سالب خفيف (`--tracking-display: -0.02em`). **بالعربي صفر تباعد وصفر uppercase** (يكسر اتصال الحروف). مفعّل تلقائياً بـ `:lang(ar)`.
- ارتفاع السطر: Display 1.05 (عربي 1.25)، نص 1.7 (عربي 1.9).
- السلّم (fluid، في `tokens.css`): `text-display` 44→100px، `text-h2` 32→60px، `text-h3` 24→32px، `text-h4` 20px، `text-lead` 18→22px، `text-body` 16px، `text-small` 14px، `text-eyebrow` 12px، `text-nav-item` ≈ 29px، `text-nav-label` ≈ 35px (القياسان الأخيران [مقاس]).

## 4. المسافات والتخطيط

- مقياس Tailwind v4 (`--spacing` 0.25rem). مسافات الأقسام `--section-y` (80→144px). هامش الصفحة `--gutter` = **40px عند 1920** [مقاس].
- أقصى عرض `90rem`، النص الطويل `42rem`. عنوان الـ Hero يلتف عند ≈ 16 حرفاً [مقاس].
- استخدم الخصائص المنطقية دائماً (`ms-*`, `pe-*`, `text-start`, `inset-inline-*`).

## 5. الشكل والارتفاع

- زوايا: **0**. استثناء: الحقول 2px (`rounded-sm`).
- ظلال: **لا شيء**. استثناء: `shadow-overlay` للقائمة فوق الصور ولأزرار الـ lightbox.
- فواصل بخط 1px (`border-line`)، وقضبان حمراء (`--rule-accent-*`) كعلامة.
- Focus: حلقة 3px بلون `focus` (أبيض على الداكن وعلى الأحمر، أسود على الفاتح).

## 6. نظام الحركة (القلب الجديد للتصميم)

### 6.1 الأدوات وتوزيع الأدوار
| الأداة | تُستخدم لـ | ممنوع لـ |
|---|---|---|
| **GSAP + ScrollTrigger + SplitText** (`@gsap/react`) | كشف النصوص، الأقسام المثبّتة، المعارض الأفقية، المسارات المرسومة بالتمرير، البارالاكس | حالات React البسيطة (hover، فتح/إغلاق) |
| **Lenis** (`lenis/react`) | التمرير الناعم، يُقاد من مؤقّت GSAP ويحدّث ScrollTrigger | اللمس: يبقى native |
| **Motion** (`motion/react`) | فتح لوحة القائمة، `AnimatePresence`، تبديل الفلاتر (`layout`)، انتقال Lightbox (`layoutId`)، الأكورديون | التمرير |
| CSS | hover بسيط، الـ Marquee، تحويلات الألوان | — |

لا تجمع GSAP وMotion على نفس العنصر. استخدم `LazyMotion` + `m` لتقليل الحجم. كل الثوابت (منحنيات، أزمنة، مسافات، media queries) من `motion.ts` فقط.

### 6.2 مكتبة الحركات (أسماء ثابتة، مكونات مشتركة)
| المكوّن | الحركة |
|---|---|
| `RevealText` | كشف سطراً سطراً بقناع (translateY 110% → 0، 0.9s، `expo.out`، stagger 0.09s). **بالعربي: بالكلمات (0.04s)، لا بالحروف أبداً.** |
| `RevealImage` | قناع `clip-path: inset()` يفتح خلال 1.1s، مع تقليص تدريجي للصورة الداخلية من 1.15 إلى 1 |
| `Parallax` | `yPercent` مربوط بالتمرير (scrub 0.6) بحد أقصى ±8% |
| `Marquee` | `transform` بـ CSS، يتوقف عند الـ hover، شبكة ثابتة عند تقليل الحركة |
| `MagneticButton` | انجذاب خفيف نحو المؤشر (فقط مع `MQ.fine`) |
| `CursorLabel` | مؤشر بكلمة "View" فوق صور المشاريع (فقط مع `MQ.fine`، `aria-hidden`) |
| `SectionHeader` | eyebrow + عنوان + قضيب أحمر يمتد من 0 إلى عرضه (0.6s) عند الدخول |
| `PageEnter` | دخول الصفحة: fade + إزاحة 16px خلال 0.6s. **بلا حركة خروج** (لتبسيط App Router) |
| `Lightbox` | Radix Dialog + Motion `layoutId` (انتقال من المصغّرة للكبيرة)، أسهم الكيبورد، Escape، swipe، `lenis.stop()` عند الفتح |

### 6.3 الحركة الأساسية (أنماط الصفحات)
- **Hero:** وسائط تهدأ من تكبير 1.12 إلى 1 خلال 2s، العنوان `RevealText`، وعند التمرير تنجرف الوسائط 15% ويخفت المحتوى (scrub).
- **أقسام مثبّتة ومعارض أفقية** (`MQ.desktop` + `MQ.fine` + `MQ.motionOK` فقط). بالموبايل: عمودي عادي بلا pin.
- **المسارات المرسومة:** `stroke-dashoffset` مربوط بالتمرير لمخطط سير العمل.
- **Hover:** القضيب الأحمر يمتد 0 → كامل العرض (200ms)، وإزاحة 8px نحو نهاية السطر. ممنوع تكبير/دوران مبالغ.

### 6.4 قواعد إلزامية
1. **تقليل الحركة:** كل حركة داخل `gsap.matchMedia()` بـ `MQ.motionOK`. عند `reduce`: لا Lenis، لا scrub، لا pin، لا marquee متحرك، المحتوى ظاهر فوراً.
2. **لا محتوى مخفي بـ JS:** HTML السيرفر يحوي كل شيء ظاهراً. الإخفاء الأولي فقط تحت `html[data-motion="ok"]` (سكربت inline بالـ head يضبطه إذا لم يُطلب تقليل الحركة). Failsafe: تُزال الصفة بعد 4s إذا لم يعمل أول كشف.
3. **تحريك `transform` و`opacity` و`clip-path` فقط.** لا width/height/top/left (استثناء: Motion `layout`).
4. **الأداء:** ScrollTrigger داخل `useGSAP` بنطاق (scope) وتنظيف عند الإزالة؛ `ScrollTrigger.refresh()` بعد تحميل الخطوط والصور؛ استورد إضافات GSAP فقط في الصفحات التي تحتاجها؛ لا فيديو تلقائي بالموبايل (صورة poster).
5. **العربي/RTL:** عكس اتجاه المعارض الأفقية، لا تقسيم بالحروف، أسهم الحركة تنعكس، لا تعكس الشعار والصور.
6. **لا قفز بالتمرير (scroll-jacking):** التمرير الناعم يُبقي سرعة التمرير الطبيعية. عند فتح القائمة أو الـ Lightbox: `lenis.stop()` ثم `start()` عند الإغلاق.
7. **الحدود:** حركة واحدة رئيسية بالقسم الواحد. لا شيء يتحرك بلا مبرر.

## 7. المكونات

### 7.1 الشعار
- `logo.png` الحالي فقط (لا vector). **أحتاج SVG أو ملف أصلي**، ونسخة بحرف G **أبيض** (الـ G الأسود يختفي على الخلفية الداكنة).
- في الهيدر أعلى بداية السطر [مقاس]. لا يُعكس بالعربي. أقل عرض 120px، ومساحة حماية ≥ 0.25 من ارتفاعه.

### 7.2 الهيدر وزر القائمة [مقاس + قرار]
- شفاف فوق الـ Hero. بعد الـ Hero يصبح بخلفية `bg` وخط سفلي `line`، ويختفي عند التمرير للأسفل ويظهر عند التمرير للأعلى.
- **زر MENU:** ثلاثة خطوط بيضاء 1px، عرض ≈ 77px، المسافة ≈ 7px، تحتها `MENU` بأحرف كبيرة ≈ 35px. نفسه على كل المقاسات (كالموقع القديم). عند الفتح تتحول الخطوط إلى ✕.

### 7.3 لوحة القائمة [مقاس + قرار]
- مستطيل أحمر `bg-accent` بلا radius، عرض يلائم أطول عنصر (≈ 202px)، padding ≈ 29px، نص أبيض ≈ 29px، مسافة بين العناصر ≈ 62px.
- `shadow-overlay` لأنها فوق صور. الفتح: Motion، تلاشي + إزاحة 8px (0.25s)، والعناصر تدخل بـ stagger 0.05s. يغلق بـ Escape والنقر خارجها. focus trap. `lenis.stop()` أثناء الفتح.
- العنصر النشط: خط أبيض سفلي 2px.

### 7.4 الأزرار [مقترح]
| النوع | الشكل |
|---|---|
| Primary | `bg-accent text-on-accent`، 700، padding 16×32px، بلا radius |
| Secondary | شفاف، حد 1px `line-strong`، نص `fg`. Hover: خلفية `fg` ونص `bg` |
| Link | نص + سهم، خط سفلي يمتد (قضيب أحمر) عند Hover. السهم ينعكس بالعربي |

### 7.5 عنوان القسم `SectionHeader` [مقترح مشتق من الشعار]
- eyebrow اختياري (أول حرف من كل كلمة بـ `accent-text`، **بدون ذلك بالعربي**) + `text-h2` + قضيب أحمر.

### 7.6 الـ Hero
- وسائط بعرض كامل (`min-height: 100svh`)، `--overlay-hero`، العنوان `text-display` أبيض بداية السطر، `max-width: 16ch`، `padding-inline: var(--gutter)`، الأزرار تحته، ومؤشر تمرير (خط رفيع يتحرك) أسفل المنتصف. الصورة بأولوية تحميل.

### 7.7 بطاقة المشروع [مقترح]
- غلاف 4:3 داخل إطار مقصوص، `--overlay-card` بسيط أسفل الصورة، العنوان `text-h3`، سطر النطاق `text-small fg-muted`، شارات الفئة (نص صغير uppercase بحد 1px). Hover: الصورة تكبر 1.04 داخل الإطار، القضيب الأحمر يمتد، `CursorLabel` "View". بلا ظلال.

### 7.8 الفلاتر
- نصوص uppercase صغيرة بصف. النشط: `bg-accent text-on-accent`. غير النشط: حد `line-strong`. الشبكة تعيد ترتيبها بحركة `layout` (Motion). تُعلن عدد النتائج لقارئ الشاشة.

### 7.9 Lightbox
- خلفية `bg-scrim`، الصورة بحجمها الطبيعي (الشهادات لقطات شاشة، لا تُكبَّر)، أزرار 44×44px، عدّاد "3 / 11"، انتقال `layoutId`، أسهم الكيبورد، Escape، swipe، focus trap.

### 7.10 النماذج
- حقل: `bg-bg-raised` + حد 1px `line-strong`، `rounded-sm`، ارتفاع 52px، التسمية فوق الحقل دائماً. Focus: خط سفلي أحمر يمتد + حلقة الـ focus. الخطأ: حد 2px + أيقونة + نص مرتبط بـ `aria-describedby`. النجاح: رسالة تظهر بحركة Motion.

### 7.11 الفوتر [مقترح]
- `bg-bg-raised`، العناوين `fg`، الروابط `fg-muted` وHover `fg`، العنوان وصندوق البريد وإنستغرام وسطر الحقوق كما بالموقع القديم.

## 8. العربي وRTL

- `dir="rtl"` و`lang="ar"` على `<html>`. خصائص منطقية فقط.
- لا تعكس: الشعار، الصور، الفيديو، أرقام الهواتف (`<bdi dir="ltr">`).
- اعكس: الأسهم، المعارض الأفقية، جهة لوحة القائمة، وجهة الـ Marquee.
- SplitText بالعربي: **كلمات أو أسطر فقط**. أرقام غربية (2024) كما بالمحتوى.

## 9. قواعد لـ Claude أثناء البناء

1. لا لون أو خط أو حجم أو مسافة مثبّتة بالـ hex/px داخل المكونات. توكنز وأصناف دلالية فقط.
2. لا لون رابع، ولا خط ثانٍ، ولا radius أكبر من 2px، ولا ظل خارج `shadow-overlay`، ولا تدرج غير التعتيم الأسود.
3. أي حركة تمرّ عبر مكونات الفصل 6.2. لا حركة ad-hoc داخل الصفحات.
4. كل حركة داخل `gsap.matchMedia()` وبثوابت `motion.ts` فقط.
5. اقرأ توثيق كل مكتبة قبل استخدامها (الإصدارات تتغير)، ولا تعتمد على الذاكرة بأسماء الواجهات.
6. كل نص عبر next-intl. كل صورة بنص بديل حقيقي. كل عنصر تفاعلي يعمل بالكيبورد.
7. بعد كل صفحة: تحقق من العربي RTL، تقليل الحركة، والموبايل، قبل الانتقال للتالية.
8. ما يقوله صاحب المشروع بخصوص التصميم يتغلب على هذا الملف: عدّله بعده.

## 10. حالة القرارات

**محسومة:** الاتجاه داكن بالغالب · IBM Plex Sans + Plex Sans Arabic · GSAP + Lenis + Motion · زوايا حادة · لا 3D حالياً · قضيب الشعار وEyebrow مفعّلان · تنقل بزر MENU ولوحة حمراء.

**مفتوحة (تحتاج الشركة):**
1. شعار vector + نسخة بحرف G أبيض.
2. أسماء العملاء/الاستشاريين/المقاولين على اللوغوهات.
3. لقطات بقية صفحات الموقع القديم (الأقسام الداخلية) للتأكد من أن الأقسام الفاتحة/الداكنة تناسب هويتهم.
4. فيديو Hero بجودة عالية (الموجود تصدير واتساب).
5. ملفات BIM/3D إن وُجدت (لمرحلة لاحقة).
